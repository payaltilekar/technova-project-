# TechNova - Static Website Hosting

## Project Overview

TechNova is a static website developed as part of my Cloud Computing Internship.

The main objective of this project was to create a static website and host it using a Linux-based web server.

## 🎯 Objective

The objective of this project is to design and host a static website using a Linux-based environment.

This project demonstrates the basic process of:

- 🌐 Developing a static website
- 🐧 Working with Ubuntu Linux
- 🖥️ Using a Virtual Machine
- 🚀 Hosting a website using Apache2 Web Server
- 📁 Managing website files on a Linux server

## 🚀 Project Implementation

The TechNova website was developed using HTML, CSS, and JavaScript and deployed in an Ubuntu Linux virtual machine.

### 🔹 Implementation Steps

1. 🖥️ Created an Ubuntu Linux virtual machine using VirtualBox.
2. 🐧 Started the Ubuntu environment and performed basic Linux operations.
3. 🌍 Installed and configured the Apache2 web server.
4. 📁 Copied the website files to the Apache2 web root directory:
   `/var/www/html`
5. ⚙️ Started and managed the Apache2 service.
6. 🌐 Accessed the website through a web browser.
7. 🐙 Uploaded the project source code to GitHub.
8. 🚀 Deployed the static website using GitHub Pages.

> 💡 **Note:** AWS EC2 and Google Cloud VM were not used in this implementation. The project was completed using an Ubuntu Linux virtual machine with Apache2 as the web server.

## 🌐 Apache2 Web Server Hosting

Apache2 was used to host and serve the TechNova static website on Ubuntu Linux.

### ⚙️ Hosting Process

1. 🐧 Set up Ubuntu Linux in a VirtualBox virtual machine.
2. 🌍 Installed the Apache2 web server.
3. 📁 Placed the website files in Apache2's default web root directory:

```text
/var/www/html

4.⚙️ Started and managed the Apache2 service.
5.🌐 Opened the website in a web browser through the Linux virtual machine environment.
💻 Apache2 Commands Used
sudo apt update
sudo apt install apache2
sudo systemctl start apache2
sudo systemctl status apache2
