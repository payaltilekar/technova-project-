# TechNova - Static Website Hosting

## Project Overview

TechNova is a static website developed as part of my Cloud Computing Internship.

The main objective of this project was to create a static website and host it using a Linux-based web server.

## Objective

To develop a static website and deploy it on a Linux virtual machine using the Apache2 web server.

## Technologies Used

- HTML
- CSS
- JavaScript
- Ubuntu Linux
- Apache2 Web Server
- GitHub
- GitHub Pages
- Virtual Machine (VirtualBox)

## Project Implementation

The project was implemented using an Ubuntu Linux virtual machine.

The TechNova website files were copied to the Apache2 web server's default directory:

`/var/www/html`

Apache2 was installed and configured on Ubuntu to serve the website.

The website was accessed through a web browser using the virtual machine environment.

## Website Features

- Modern static website design
- Responsive webpage layout
- Hero section with background image
- Cloud computing related content
- Images and visual elements
- CSS-based styling
- JavaScript functionality
- Multiple website sections
- Navigation and interactive elements
